# \# FoodFlow Showcase

# 

# FoodFlow is a restaurant ordering and admin system designed for small restaurants, cafés, food trucks, and local food businesses that need a cleaner way to show their menu, receive orders, and manage daily operations.

# 

# This repository is a public showcase only. The full source code is private.

# 

# \## Overview

# 

# FoodFlow helps restaurants move from informal WhatsApp-only ordering to a more organized digital flow:

# 

# \- Customers browse a digital menu.

# \- They add products to a cart.

# \- They choose pickup, dine-in, or delivery.

# \- They select a payment method such as cash, local card payment, or SINPE Móvil.

# \- The restaurant manages the order from an admin panel.

# \- Staff can update order status and product availability.

# 

# \## Main Features

# 

# \- Public digital menu

# \- Product search

# \- Category filters

# \- Persistent cart

# \- Public order form

# \- Pickup, dine-in, and delivery flows

# \- Manual SINPE payment flow

# \- Order confirmation page

# \- Admin panel with Laravel Filament

# \- Product and category management

# \- Product availability control

# \- Product duplication

# \- Order status management

# \- Customer loyalty module

# \- Activity log

# \- Role-based access for super admin, owner, and staff

# 

# \## Tech Stack

# 

# \- Laravel

# \- Filament

# \- Livewire

# \- MySQL / MariaDB

# \- Blade

# \- Hostinger deployment

# 

# \## Project Status

# 

# FoodFlow is currently in demo/pilot stage. The system is being tested as a commercial solution for small restaurants that need a simple and manageable ordering platform.
